## Sobre o projeto

O **Projeto Amor de Patas** é um site desenvolvido para uma ONG fictícia de proteção e resgate de animais.

O projeto foi criado com o objetivo de representar uma organização que atua no resgate, cuidado e busca por novos lares para animais em situação de abandono.

Além de apresentar informações sobre a ONG e os animais disponíveis para adoção, o site permite que o visitante demonstre interesse em **adotar, ser voluntário ou realizar uma doação**.

## Objetivo

Desenvolver uma página web institucional, responsiva e interativa, aplicando na prática conhecimentos de **HTML5, CSS3 e JavaScript** adquiridos durante o curso de Análise e Desenvolvimento de Sistemas.

## Funcionalidades

- Navegação entre as seções do site
- Apresentação dos animais disponíveis para adoção
- Formulário de interesse
- Validação dos campos do formulário
- Seleção do animal diretamente pelo card de adoção
- Preenchimento automático da mensagem
- Mensagem de confirmação após o envio
- Layout responsivo para diferentes tamanhos de tela
- Links e ícones para redes sociais
- Descrição do conteúdo da página em áudio
- Integração com VLibras para acessibilidade

## Tecnologias utilizadas

### Front-end

- **HTML5** — estrutura e semântica da página
- **CSS3** — estilização, responsividade e efeitos visuais
- **JavaScript** — interatividade, eventos e validação do formulário
- **Font Awesome** — ícones utilizados no projeto
- **VLibras** — recurso de acessibilidade em Libras
